# Family OS 產品需求規格書

## 1. 產品定位

Family OS 是一個給多家庭使用的家庭協作平台，整合個人記帳、家庭基金、任務、積分、願望兌換與權限管理，讓家庭成員可以用透明、可追蹤、可協商的方式管理生活、金錢與承諾。

產品目標是做成可盈利產品，支援多個家庭註冊使用。

## 2. MVP 範圍

MVP 包含：

- 帳號與家庭
- 家庭成員與角色權限
- 個人記帳本
- 共用基金記帳本
- 任務清單
- 積分系統
- 願望清單與獎勵兌換
- 通知系統
- 免費 / 付費方案
- 管理後台

MVP 暫不包含：

- 行程表
- 相簿
- 備忘錄
- 訂閱管理
- 信用卡帳單週期
- 多種積分類型

## 3. 帳號與家庭

### 功能需求

- 使用者可以註冊帳號。
- 使用者可以建立家庭。
- 使用者可以加入多個家庭。
- 家庭管理者可以邀請成員。
- 家長可以建立兒童簡易帳號。
- 兒童帳號不需要 Email / 手機。
- 家庭需支援角色：
  - 家庭擁有者
  - 管理者
  - 一般成員
  - 兒童成員
  - 訪客 / 只讀成員

### 驗收條件

- 一個使用者可切換不同家庭。
- 不同家庭的資料、積分、任務、願望互相隔離。
- 兒童帳號只能被所屬家庭管理者建立與管理。

## 4. 權限系統

### 功能需求

- 採混合權限：
  - 角色提供預設權限。
  - 特定資源可覆寫權限。
- 權限需支援：
  - 查看
  - 新增
  - 編輯
  - 刪除
  - 審核
  - 調整積分
  - 管理基金
  - 匯出資料
- 共用基金需能設定誰可查看、存入、支出、編輯、刪除。
- 任務建立、手動調分、願望管理皆依權限判斷。

### 驗收條件

- 無權限者不能透過 UI 或 API 操作受限資源。
- API 層必須重新驗證權限，不能只依賴前端隱藏按鈕。
- 權限變更後，使用者下一次操作即套用新權限。

## 5. 個人記帳本

### 功能需求

- 每位使用者有個人記帳本。
- 個人記帳本下可建立多個帳戶，例如現金、銀行、電子支付、其他。
- 每筆交易需綁定一個帳戶。
- 查看某帳戶時，只顯示該帳戶交易。
- 第一版不做信用卡帳單週期。
- 交易類型包含收入與支出。
- 轉帳可放第二階段。
- 分類由系統提供預設，使用者可新增。
- 支援離線新增個人記帳。
- 離線資料回網路後同步。

### 分享層級

- 不分享
- 只分享總餘額
- 分享分類統計
- 分享部分交易
- 分享完整帳本

### 驗收條件

- 現金帳戶的早餐 -80 不會出現在銀行 A 帳戶交易列表。
- 使用者設定不分享時，家庭其他成員看不到任何個人帳本資訊。
- 使用者設定只分享總餘額時，其他人只能看到總餘額。
- 離線新增交易後，回網路可同步到雲端。

## 6. 共用基金記帳本

### 功能需求

- 一個家庭可以建立多個共用基金。
- 共用基金只記錄 App 內基金餘額，不綁定現實銀行帳戶。
- 基金交易類型包含存入與支出。
- 每筆基金交易需記錄：
  - 金額
  - 類型
  - 分類
  - 操作者
  - 備註
  - 發生時間
- 有查看權限者可看到基金詳細交易紀錄。
- 沒有權限者不能看到基金存在或細節，依設定決定。
- 共用基金不支援離線修改。

### 驗收條件

- 爸爸存入 1000，基金餘額增加 1000。
- 媽媽支出 500，基金餘額減少 500。
- 小孩沒有支出權限時，不能新增支出。
- 有權限者可代記小孩存入，並在備註標明。

## 7. 預算與報表

### 功能需求

- 支援個人帳本與共用基金預算。
- 預算期間支援每月與自訂期間。
- 超預算仍可繼續記帳。
- 超支時預算餘額顯示負數。
- MVP 報表包含：
  - 月支出分類圓餅圖
  - 帳戶餘額
  - 共用基金餘額
- 免費版報表只看近 3 個月。
- 付費版提供進階報表與匯出。

### 驗收條件

- 預算 3000，實際支出 3500 時，剩餘顯示 -500。
- 免費版無法查看超過 3 個月以前的報表。
- 付費版可匯出 Excel / CSV。

## 8. 任務清單

### 功能需求

- 任務建立依權限設定。
- 任務指派方式支援單一成員、多位成員、不指定任何人。
- 任務可設定標題、說明、最高積分、期限、重複規則、發分模式。
- 發分模式：
  - 自動發分：完成打勾後立即發放設定分數。
  - 審核發分：完成後由審核者給予 0 到最高積分。
- 第一版證明方式：打勾即可。
- 重複任務需自動生成下一期。

### 驗收條件

- 自動發分任務完成後，使用者積分立即增加。
- 審核任務完成後，不會立即加分，需審核者確認。
- 審核者不能發超過任務設定上限的分數。
- 重複任務完成後，系統產生下一次任務。

## 9. 積分系統

### 功能需求

- 積分以家庭為單位獨立計算。
- 同一使用者在不同家庭有不同積分餘額。
- 積分來源包含任務自動發放、任務審核發放、有權限者手動調整、願望兌換扣除。
- 每次積分變動都要有紀錄。
- 不支援多種積分。

### 驗收條件

- 使用者在家庭 A 有 100 分，不影響家庭 B 的積分。
- 每次加分、扣分、調整分數都能查到紀錄。
- 無權限者不能手動調整他人積分。

## 10. 願望清單與獎勵兌換

### 功能需求

- 成員可以提出願望。
- 願望可指定實現者。
- 願望流程：
  1. 提出願望
  2. 實現者接受或駁回
  3. 接受後進入定價
  4. 雙方同意價格
  5. 願望進行中
  6. 提出者累積積分
  7. 提出者兌換願望
  8. 系統扣除積分
  9. 實現者標記已完成

### 願望修改規則

- 願望提出者可隨時刪除願望，不需實現者同意。
- 實現者駁回時可單方面結束願望。
- 願望進入合作狀態後，實現者刪除願望需提出者同意。
- 雙方都可提出修改價格。
- 修改價格需雙方同意。
- 提出者不同意價格，等同刪除願望。

### 驗收條件

- 願望未被實現者接受前，不能定價。
- 價格未經雙方同意前，不能開始兌換。
- 積分不足時不能兌換。
- 兌換後立即扣分，狀態變成待實現。
- 實現者標記完成後，願望狀態變成已完成。

## 11. 同步與離線

### 功能需求

- 離線時只允許新增個人記帳。
- 協作功能不允許離線修改：
  - 共用基金
  - 任務
  - 願望
  - 積分
  - 權限
- 預設每 30 分鐘同步一次。
- 使用者重新整理後可取得最新資料。
- 修改協作資料前，系統需檢查是否有未同步資料。
- 若有未同步資料，需先同步完成才能修改協作功能。

### 驗收條件

- 離線時可新增個人記帳交易。
- 離線時不能新增共用基金交易。
- 離線時不能完成任務或兌換願望。
- 回網路後，個人記帳交易可同步。
- 有未同步資料時，系統阻止使用者修改協作功能。

## 12. 通知系統

### 通知事件

- 任務被指派
- 任務待審核
- 積分被發放
- 積分被手動調整
- 願望被接受
- 願望被駁回
- 願望價格待同意
- 願望可兌換
- 願望已兌換
- 預算超支

### 通知類型

- App 內通知
- Web Push 推播

### 驗收條件

- 任務被指派時，受指派者收到通知。
- 審核任務完成時，審核者收到待審核通知。
- 預算超支時，相關使用者收到通知。
- 使用者可在 App 內查看歷史通知。

## 13. 商業模式

### 免費版

- 有廣告
- 家庭成員數限制
- 任務數限制
- 願望數限制
- 報表只看近 3 個月

### 付費版

- 去廣告
- 無限成員
- 進階報表
- 多主題
- 匯出 Excel / CSV
- 更多儲存空間

### 廣告位置

- 首頁資訊流
- 報表頁底部
- 免費版切換頁面時

## 14. MVP 開發順序建議

1. 帳號、家庭、角色權限
2. 個人記帳本與帳戶
3. 共用基金
4. 積分流水
5. 任務清單
6. 願望與兌換狀態機
7. 通知
8. 報表
9. 免費 / 付費限制
10. 管理後台
