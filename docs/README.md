# Family OS Documentation

此資料夾保存 Family OS 的產品需求、系統設計、資料流程、用戶流程與測試規格。

Family OS 是一個給多家庭使用的家庭協作平台，MVP 聚焦在個人記帳、家庭共用基金、任務、積分、願望兌換與權限管理。
